# 橐龠海报工坊

一个面向会议纪实、班会复盘和论坛活动的结构化海报编辑器。经典版宽度为 820px；切换不等宽或多栏布局时，画布会在保持标准栏宽的前提下自动向右扩展。最小高度为 1220px，内容增加时也会自动向下延长；支持导出 2×、3× 或 4× PNG。

编辑器采用“容器 → 组件 → 内容项”结构：容器负责版面区域，组件负责自动排版，用户只需要配置文字和图片。

## 使用

```powershell
npm install
npm run dev
```

打开终端显示的本地地址即可编辑。生产构建使用：

```powershell
npm run build
```

## Tauri 2 桌面版

项目已经接入 Tauri 2，可直接复用现有 React/Vite 编辑器运行 Windows 桌面版：

```powershell
npm run tauri dev
```

生成 Windows MSI 与 NSIS 安装包：

```powershell
npx tauri build --no-sign
```

安装包会输出到 `src-tauri/target/release/bundle/`。后续接入系统文件保存、原生文件选择器和移动端能力时，可通过 `@tauri-apps/api` 与 Tauri 插件扩展。

## Tauri 2 Android 版

Android 工程已生成在 `src-tauri/gen/android/`。准备好 JDK 17、Android SDK/NDK 和 Rust Android target 后，可执行：

```powershell
npx tauri android init --ci --skip-targets-install
npx tauri android build --debug --apk --target aarch64 --ci
```

Debug APK 适合直接安装测试；正式发布时使用 `--release --apk` 或 `--aab` 并配置签名。Windows 构建目录建议使用纯 ASCII 路径，避免 Android Gradle 和 NDK 链接器对中文路径的兼容问题。

## 已实现

- 顶部提供“海报编辑 / 模板中心 / 我的项目”三个页面入口
- 模板中心预置经典双栏、三栏论坛、新春团拜、激励表彰和单栏长图 5 种可编辑模板
- 点击“保存”会覆盖当前项目，“另存为”会创建独立版本；项目默认以海报主标题命名，并自动截取真实海报画面作为缩略图；“我的项目”同时支持自定义封面、重命名、复制、删除和重新打开
- 模板中心支持将当前海报保存为个人模板；使用个人模板时会创建新的可编辑项目，不会改动模板原件
- 海报编辑器顶部提供“存为模板”快捷入口；三页主导航固定居中，切换页面时不会因右侧操作区变化而位移
- 默认留空的全局页头、全局页脚与五个可复用内容栏；全局区域有内容时可跨越完整画布宽度
- 12 套布局预设：经典双栏、单栏、等宽/不等宽双栏、等宽/重点三栏、等宽/重点四栏、等宽/重点五栏
- 标准内容栏保持 392px，重点栏扩展为 588px；新增栏和宽栏通过增加海报宽度实现，不压缩现有栏
- 每栏支持 1–5 倍宽度设置；双栏提供从 1:1 到 1:5，以及反向 2:1 到 5:1 的快捷比例
- 主标题和会议信息在所有布局中默认位于第一栏；需要跨栏内容时，可将组件添加到全局页头
- 布局级“跟随预设 / 大容器 / 独立卡片”控制，每个组件可用“跟随 / 显示 / 隐藏”单独覆盖
- 9 套正向氛围背景，包含“新春喜庆”“激励表彰”以及庄重典礼使用的“大红鎏金”风格；鎏金主题采用纯朱红礼仪底、统一象牙宣纸容器、暗金双线边框与局部金箔文字
- 每套背景同时协调底色、弥散光斑、强调色与正文色；全部预设已按正文、标题和按钮文字的可读性重新校正，也可继续自定义颜色
- 画布支持 20%–200% 缩放，超宽多栏海报可放大检查细节
- 属性设置栏提供粘性分区导航，可快速跳转内容设置与显示设置；返回按钮遵循“内容项 → 所属组件 → 上级组件 → 容器”的逐级关系
- 属性栏顶部采用独立返回箭头与层级路径，分区导航使用轻量文字标签，避免与操作按钮混淆
- 海报结构树按页头、当前版式实际栏目、页脚顺序显示，未被当前栏数使用的中栏不会出现
- 主题标题、会议信息、嘉宾组、参会照片网格、图片区、多行文本和页脚署名组件
- 横向组件组支持在同一栏内并列放置 2–4 个真实子组件，可设置 1–5 权重比例、组件间距和每个位置的组件类型
- 主标题默认居中，主标题与副标题可分别设置字号；副标题支持实线、双线、虚线、渐隐、五角星、菱形、圆点和无装饰；页脚署名支持字号设置
- 页脚署名的品牌文字和附加说明支持分别设置字号；五角星装饰为左右各三星，菱形装饰采用实线—菱形—实线组合
- 演示嘉宾姓名、班级名称与职务由模板初始化时自动组合生成，重置模板可获得新一组示例内容
- 多行文本支持显式换行、字号、行距与对齐设置
- 标题和多行文本统一使用“左 / 中 / 右”按钮控制对齐
- 参会人员照片网格支持 0–20px 照片间距，并同步参与自动列数计算
- 新增参会照片网格默认预置 20 个照片位，批量上传后仍以实际图片数量自动更新
- 参会照片网格组件读取所在栏目的真实宽度，以稳定的标准内容高度遍历可用排法；网格间距始终保持为用户设置值并透出当前容器背景，无法铺满的余量统一保留在底部，所有照片保持 16:9
- 上传真实照片后，参会组件通过尺寸观察器读取当前容器的真实内容宽度；切换布局或栏宽比例时会重新计算列数和照片尺寸，不沿用旧布局尺寸
- 海报顶部与底部留白支持 0–160px 独立滑块控制
- 会议信息、嘉宾组、参会网格、图片区和多行文本的标题为空时，不渲染标题胶囊及其占位间距
- 嘉宾数量变化时自动排列；超过 6 人时自动切换为 3 列
- 所有人物照片统一使用 16:9 比例并自动居中裁切
- 参会人员组件支持批量上传多张照片，每张照片独立进入 16:9 网格
- 已上传的参会照片支持拖拽排序、前移、后移和单张移除
- 海报高度根据左右栏实际内容自适应，组件不会因固定画布高度被裁切
- 表单化修改标题、说明、嘉宾姓名、身份和图片
- 上传 PNG、JPG、WebP 图片或会议截图，自动压缩优化以便本地存档
- 组件树选择、显隐、复制、删除和顺序调整
- 容器背景、内边距、组件间距与圆角设置
- 撤销、重做、本地保存及恢复
- 2× / 3× / 4× 高清 PNG 导出，导出时自动移除仅用于编辑预览的点阵纹理和选中辅助线

项目只在浏览器本地运行，不会上传用户图片。
